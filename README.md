# EyeSight
AI-Powered Visual Assistance for the Visually Impaired

About
EyeSight is an AI-powered assistant designed to help blind and visually impaired people understand their surroundings. Using a smartphone camera, artificial intelligence, and voice interaction, the system describes nearby objects, reads signs, and answers questions about the environment.

Users can ask questions such as:
What is in front of me?
What does that sign say?
What was written on the door I just passed?

Main Features

Live video streaming from a smartphone camera.
Image processing and intelligent frame selection.
Text recognition (OCR) and object detection.
Multimedia database for storing and retrieving visual information.
Voice-based questions and spoken AI-generated answers.
Web dashboard for monitoring the live stream and reviewing stored frames and conversation history.

Project Goal
To make visual information more accessible through real-time AI-powered descriptions and voice interaction.

Safety and Privacy
EyeSight is an assistive tool, not a replacement for a white cane or guide dog. It must acknowledge uncertainty, avoid claiming that something is safe, protect user privacy, and delete old frames according to the project's data-retention policy.
